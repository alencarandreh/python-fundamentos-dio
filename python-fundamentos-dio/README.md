# Python: fundamentos (DIO)

Exercícios que fiz durante o bootcamp **Accenture – Python para Análise e Automação de Dados**, da [DIO](https://www.dio.me), no módulo *Fundamentos Essenciais de Python para Análise de Dados*.

Este repositório é o meu registro de estudo. O bootcamp está **em andamento** e vou atualizar o repositório a cada módulo concluído.

## O que já pratiquei

| Pasta | Conteúdo |
|---|---|
| `01-basico` | primeiro programa, variáveis e constantes, tipos de dados, conversão de tipos |
| `02-entrada-e-saida` | `input()` e `print()` com `sep` e `end` |
| `03-operadores` | aritméticos, atribuição, comparação, lógicos, associação (`in`) e identidade (`is`) |
| `04-estruturas-condicionais` | `if`/`elif`/`else`, condicionais aninhadas e expressão ternária |
| `05-estruturas-de-repeticao` | `for` (com iterável e `range`), `while` e `break` |
| `06-blocos-e-funcoes` | identificação de blocos por indentação e definição simples de funções |
| `desafios` | três desafios de código do curso (entrada de dados e soma) |

## Como executar

Precisa de Python 3 instalado.

```bash
python 03-operadores/logicos.py
```

Alguns exercícios pedem dados no terminal (`input`), como `desafios/desafio_3.py`.
